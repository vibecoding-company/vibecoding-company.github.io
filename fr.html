~/prototypes

Prototypes et MVP

Nous créons des services web, des bots, des plugins et des SaaS autour d'un problème précis du marché. Le but : tester l'hypothèse auprès de vrais utilisateurs avant d'investir dans le développement.

Ce que vous obtenez

  • Un prototype fonctionnel sur des données réelles, pas une maquette
  • Le code dans votre dépôt et un guide de lancement
  • Des analytics : ce que font les utilisateurs et où ils décrochent
  • Un plan pour passer en production

Formats et délais

  • Prototype — 1 à 3 jours
  • Série d'hypothèses — 5 à 10 MVP par mois
  • Outil pour un client B2B — pendant le rendez-vous ou dans les 24 heures

Prix — après le brief

~/agents

Agents IA, pipelines et audit

Ce sont les réseaux neuronaux qui écrivent le code ; le vrai travail consiste à les piloter. Nous configurons des agents et des pipelines pour votre équipe et veillons à ce que le code reste lisible et évolutif.

Ce que vous obtenez

  • Des chaînes d'agents qui écrivent, testent et déploient le code
  • Un pipeline unique avec Claude Code, Cursor, Replit ou GitHub Copilot
  • Des règles pour les agents : style de code, tests, relecture
  • Un audit d'architecture : rapport de risques et plan de correction

Formats et délais

  • Audit du code — 3 à 5 jours
  • Mise en place du pipeline — 1 à 2 semaines
  • Formation de l'équipe — 2 sessions de 2 heures

Prix — après le brief

~/design

Design produit et UX/UI

Quand le code ne coûte presque rien, c'est le produit le plus simple à utiliser qui gagne. Nous partons du problème de l'utilisateur et finissons par une interface à votre image.

Ce que vous obtenez

  • Entretiens et analyse de l'audience : ce qui fait mal et ce pour quoi on paie
  • Un cahier des charges précis pour l'IA — sans « faites joli »
  • Une interface à votre image au lieu d'écrans génériques
  • Un design system : couleurs, polices, composants

Formats et délais

  • Recherche — 2 à 3 jours
  • Interface du prototype — 2 à 5 jours

Prix — après le brief

~/qualité

Claude écrit le code, nous répondons de la qualité

On reproche au vibe coding un code que personne ne comprend. C'est pourquoi nous avons six règles.

Chaque modification est relue par un humain

Relecture avant chaque mise en ligne. Un code que personne n'a compris ne part pas en production.

Des tests pour les scénarios clés

Paiement, inscription, données clients — tout ce qui ne doit pas casser.

Contrôle de sécurité

Dépendances, secrets et droits d'accès. Les clés sont stockées dans un coffre à secrets, pas dans le code.

Une architecture évolutive

Des modules et une structure claire au lieu de spaghettis. Le code tiendra la version suivante.

Le code et les accès sont à vous

Le dépôt est dans votre GitHub ou GitLab dès le premier jour.

Documentation

Comment lancer, où se trouve quoi et que modifier — pour votre équipe et pour le prochain agent.

~/questions

Questions fréquentes

Qui écrit le code ?

Claude écrit le code. Nous posons la tâche, vérifions chaque modification et répondons du résultat.

À qui appartient le code ?

À vous. Nous créons le dépôt dans votre GitHub ou GitLab et vous remettons les accès et un mode d'emploi après la mise en ligne.

Et si le prototype ne marche pas ?

Alors l'hypothèse a été testée en quelques jours, pas en quelques mois. Nous analysons ce que les utilisateurs ont montré et construisons la version suivante.

Travaillez-vous sur du code existant ?

Oui. Nous commençons par un audit : architecture, tests et sécurité — puis nous poursuivons le développement.

Pouvez-vous connecter des agents IA à notre équipe ?

Oui. Nous configurons Claude Code, Cursor ou GitHub Copilot pour votre processus et formons l'équipe à travailler avec les agents.

Combien ça coûte ?

Nous calculons après le brief : le prix dépend du périmètre, des intégrations et des exigences de sécurité. L'estimation arrive avant le début des travaux.
