~/prototypes

Prototypes and MVPs

We build web services, bots, plugins and SaaS around a specific market pain. The goal is to test the hypothesis with real users before you invest in development.

What you get

  • A working prototype on real data, not a mockup
  • Code in your repository and a launch guide
  • Analytics: what users do and where they drop off
  • A plan to bring it to production

Formats and timelines

  • Prototype — 1–3 days
  • A series of hypotheses — 5–10 MVPs a month
  • A tool for a B2B client — at the meeting or within a day after it

Price — after the brief

~/agents

AI agents, pipelines and audit

Neural networks write the code, so the main job is managing them. We set up agents and pipelines for your team and make sure the code stays understandable and scalable.

What you get

  • Agent chains that write, test and deploy code
  • One pipeline from Claude Code, Cursor, Replit or GitHub Copilot
  • Rules for agents: code style, tests, review
  • Architecture audit: a risk report and a fix plan

Formats and timelines

  • Code audit — 3–5 days
  • Pipeline setup — 1–2 weeks
  • Team training — 2 sessions of 2 hours

Price — after the brief

Formats and timelines

~/quality

Claude writes the code, we answer for quality

Vibe coding is criticised for code nobody understands. That is why we have six rules.

A person reads every change

Review before every release. Code nobody understood doesn't go to production.

Tests for key scenarios

Payments, sign-up, customer data — everything that must not break.

Security check

Dependencies, secrets and access rights. We keep keys in a secrets vault, not in the code.

Architecture built to grow

Modules and a clear structure instead of spaghetti. The code will survive the next version.

Code and access are yours

The repository lives in your GitHub or GitLab from day one.

Documentation

How to run it, where things are and what to change — for your team and for the next agent.

~/questions

Frequently asked questions

Who writes the code?

Claude writes the code. We set the task, check every change and answer for the result.

Who owns the code?

You do. We set up the repository in your GitHub or GitLab and hand over access and a manual after release.

What if the prototype doesn't work?

Then the hypothesis was tested in days, not months. We will go through what users showed and build the next version.

Do you work with existing code?

Yes. We start with an audit: architecture, tests and security — then we build on it.

Can you connect AI agents to our team?

Yes. We set up Claude Code, Cursor or GitHub Copilot for your process and teach the team to work with agents.

How much does it cost?

We calculate after the brief: the price depends on scope, integrations and security requirements. We will send an estimate before work starts.
