~/quality

代码由 Claude 编写，质量由我们负责

氛围编程常被批评写出没人看得懂的代码。所以我们有六条规则。

每处改动都有人审阅

每次发布前都会审查。没人看懂的代码不会进入生产环境。

关键场景必有测试

支付、注册、客户数据 — 一切不能出错的地方。

安全检查

依赖、密钥和访问权限。密钥存放在密钥库中，而不是写在代码里。

面向增长的架构

模块化、结构清晰，拒绝意大利面式代码。下一个版本也撑得住。

代码和权限归您所有

从第一天起，代码仓库就在您的 GitHub 或 GitLab 中。

文档

如何启动、东西放在哪、改哪里 — 写给您的团队，也写给下一个智能体。

~/questions

常见问题

代码是谁写的？

代码由 Claude 编写。我们设定任务、审查每一处改动，并对结果负责。

代码归谁所有？

归您所有。我们在您的 GitHub 或 GitLab 中创建仓库，发布后交付访问权限和使用说明。

如果原型没有效果怎么办？

那说明假设在几天内而不是几个月内得到了验证。我们会分析用户的反馈，再做下一个版本。

可以接手现有代码吗？

可以。我们先做审计：架构、测试和安全 — 然后继续开发。

能为我们的团队接入 AI 智能体吗？

能。我们会根据您的流程配置 Claude Code、Cursor 或 GitHub Copilot，并培训团队与智能体协作。

费用是多少？

在需求简报之后计算：价格取决于工作量、集成需求和安全要求。我们会在开工前发送估价。
